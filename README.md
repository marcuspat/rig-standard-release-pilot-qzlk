# Turbo Rig release pilot

![Animated release pilot workflow](docs/assets/banner.svg)

This repository is a small static site for the Turbo Rig GitHub release pilot. It exercises a reviewed release candidate, a GitHub Pages deployment, and a versioned GitHub Release.

- [Open the GitHub Pages site](https://marcuspat.github.io/rig-standard-release-pilot-qzlk/) and select **View release checks**.
- [Read the release checklist](docs/checks/index.html) or [open the workflow infographic](docs/assets/workflow.svg).
- Download the [v0.1.1 landing archive](https://github.com/marcuspat/rig-standard-release-pilot-qzlk/releases/download/v0.1.1/rig-standard-release-pilot-qzlk-v0.1.1-landing.zip) and its [SHA256SUMS](https://github.com/marcuspat/rig-standard-release-pilot-qzlk/releases/download/v0.1.1/SHA256SUMS). Check the archive against the matching line before extracting it. The archive contains the static site under `docs/`.
- The [changelog](CHANGELOG.md), [MIT license](LICENSE), and [security reporting policy](SECURITY.md) are in this repository.
